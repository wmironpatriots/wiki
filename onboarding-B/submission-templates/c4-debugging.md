# C.4: Debugging Report

## Bug

What should have happened, and what happened instead?

## Reproduction

List the steps and controls needed to reproduce the bug.

## Evidence before the fix

Link the failing trace or recording. Identify the signals that showed the cause.

## Cause and fix

Explain the code change and include the fix commit.

## Result after the fix

Run the same scenario again and link the passing trace or recording.
