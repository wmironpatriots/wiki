# Onboarding B: Mechanisms

Follow [Onboarding B](https://github.com/wmironpatriots/wiki/wiki/onboarding-b) in order.

In B.8, create your own Java OpMode project here with WPILib's project creator. Name it `mechanism-sim` and enable desktop support. Open that project folder in WPILib VS Code.

```text
onboarding-B/
  mechanism-sim/                Created by you in B.8
    build.gradle
    gradlew
    gradlew.bat
    gradle/
    src/
    docs/
      b8-roller.md
      b10-flywheel.md
      c4-integration.md
      c4-debugging.md
      evidence/
  submission-templates/         Copy the relevant notes into the project's docs/
```

The destination is left uncreated so the project creator can generate it. Keep the generated project files and package names. Use that same project for B.10 and C.

Ask for review after B.8, B.10, and C.4. Keep using your username branch and onboarding PR.

The `examples/` and `evaluations/` directories contain additional mechanism code. They use their own dependencies; B.8 starts with a fresh project rather than those projects.
