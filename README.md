# 6423 Software Onboarding

The readings and assignments are in the [wiki](https://github.com/wmironpatriots/wiki/wiki). This repository holds your code and submission files.

## Getting started

1. Clone this repository.
2. Create one branch named after your GitHub username.
3. Keep all onboarding work on that branch and use one onboarding PR for reviews.

See the [GitHub workflow](https://github.com/wmironpatriots/wiki/wiki/git-and-github-workflow) for the commands.

## Where your work goes

```text
onboarding-A/
  fibonacci/                    A.2: write your Java program here
  elevator/                     A.3: Java code and the provided test
onboarding-B/
  submission-templates/         Notes templates to copy as needed
  mechanism-sim/                You create this project in B.8
    src/
    docs/
      b8-roller.md
      b10-flywheel.md
      c4-integration.md
      c4-debugging.md
      evidence/
```

The `mechanism-sim` project isn't supplied. Create it with WPILib's project creator in B.8, then extend the same project for B.10 and C.

Each assignment page lists the code and results to submit. Commit source, build configuration, the Gradle wrapper, and small evidence files. Keep build output and caches out of Git.
